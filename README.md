# Dynamic Routine Planner & Timetable Optimizer

A flexible weekly routine and timetable planning interface designed to balance intense academic preparation, technical skill development, personal wellness, and burnout prevention.

## Highlights
- **Interactive Weekly Schedule Canvas:** Intuitive drag-and-drop timeline grid for daily block scheduling.
- **Academic Deadlines:** Dedicated tracking for upcoming milestones including GATE (109-day countdown) and College Exams (30-day countdown).
- **Attendance & Commitment Guard:** Preserves non-negotiable sessions (Machine Learning and Lab practicals) while identifying flexible theory slots.
- **Burnout Mitigation:** Reserves fixed windows for daily commutes, morning prep, recovery meals, running/cardio, and guilt-free leisure.
- **Collision Detection:** Automatic overlap checking across planned commitments.
